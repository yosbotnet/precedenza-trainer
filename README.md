# Precedenza — right-of-way trainer

A browser game for practising Italian right-of-way rules (precedenza) at junctions and roundabouts, for the driving test.

- **Read the signal**: predict where a car goes from its blinker.
- **Who goes first?**: random junctions with signs (or none). Tap the cars in the order they go.
- **Roundabout live**: set your blinker and choose a safe gap.

It's a single self-contained `index.html` (three.js loaded from a CDN).
